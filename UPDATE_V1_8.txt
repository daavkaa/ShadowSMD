PLAYTIME:
- New project -> нэр, client, lead, start/delivery date, scope оруулна.
- Project нээгээд Add task / step дарж жижиг task-уудаа нэг нэгээр нэмнэ.
- Task бүр title, designer/manager, date/deadline, process, urgency-тай.
- Task-ууд 01, 02, 03 гэсэн дарааллаар нэг project дотор харагдана.
- Up/down сумнууд database-д дарааллыг хадгална. Шинэ task төгсгөлд нэмэгдэнэ.
- Одоо байгаа project task-ууд эхний удаа assigned time-аараа эрэмбэлэгдэнэ.
- Алхамын дугаар нь харагдах дараалал; өмнөх алхам дуусахыг албадан хүлээлгэхгүй.
- Task-ийн urgency-г тухайн мөр дээрээс шууд Low / Normal / Urgent сонгоно.
- Project urgency = дуусаагүй task-уудын ХАМГИЙН ӨНДӨР urgency.
- Approved/Ready, Scheduled, Cancelled, Rejected task-ууд urgency-г өсгөхгүй.
- Нээлттэй task байхгүй бол No open work гэж харуулна.
- Хоцорсон task-ийг тусад нь overdue гэж харуулна; urgency-г автоматаар
  өөрчлөхгүй. Project-ийн status гар аргаар өөрчлөгддөг хэвээр.
- Card дээр next unfinished step, ready task count, progress, overdue count.
- Task-ууд Task Management-тэй нэг өгөгдөлтэй. Давхар task үүсгэхгүй.
- Management task-уудын дарааллыг солино; өөрийн task-тай ажилтан urgency-г
  өөрчилж болно. Эрхийн шалгалтууд database RPC дээр хэрэгжинэ.
